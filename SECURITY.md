# Security Policy

## Reporting a Vulnerability

Security issues are taken seriously. If you discover a security vulnerability in this project, please report it privately rather than opening a public issue.

### Preferred Reporting Method

Please report vulnerabilities using **GitHub Private Vulnerability Reporting**:

1. Navigate to the main repository page on GitHub.
2. Click on the **Security** tab.
3. Under "Reporting", click **Report a vulnerability**.
4. Provide details of the vulnerability, including steps to reproduce, potential impact, and suggested mitigation if available.

### What to Expect

- Your submission will be acknowledged promptly.
- A fix or mitigation will be investigated and addressed.
- You will be credited for the discovery once the advisory is published, if desired.
